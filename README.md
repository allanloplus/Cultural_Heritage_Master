# 文資達人訪查

網址：**https://cultural-visit.123hi.org/**（GitHub Pages 自訂網域，見 `CNAME`）

「[Allan Lo 和你逛文化](https://cultural.123hi.org/)」的姊妹站。知識網站介紹文化資產的歷史；本站由經審查核准的**文資達人**實地走訪，記錄每處文資的**現況與推薦**：參訪日期、保存現況、開放情形、心得與心情、實地照片、推薦指數，以及附近的美食、住宿、交通推薦。

- 規劃書：[`docs/PLAN.md`](docs/PLAN.md)（目標、角色、流程、欄位、統計、架構、資安與個資、上線步驟、分期）
- 規劃設計：Allan Lo，https://www.123hi.org

## 功能

| 頁面 | 說明 |
|---|---|
| 總覽 `#home` | 全臺文資數、已訪查、覆蓋率、近一年更新、紀錄數、達人數；最新訪查；達人即將到訪 |
| 查核資訊 `#coverage/<類別>` | 有形文資、無形文資、古物**分開統計**：各縣市數量、已訪查、覆蓋率、近一年、需回訪、預計到訪、紀錄筆數；依類別或等級覆蓋率；下載三類 CSV |
| 縣市 `#county/<縣市>/<類別>` | 三個分頁列出每筆的最近紀錄與現況，可篩選未訪查、需回訪；達人可**規劃訪查行程**（跨分頁勾選＋起訖日期） |
| 文資 `#site/<縣市>/<id>` | 一筆文資的所有紀錄、最新現況、平均推薦、附近推薦；連到知識網站同一處文資或展示點 |
| 展示點 `#venue/<縣市>/<展示點 id>` | 該展示點的無形文資與古物及紀錄狀態 |
| 達人 `#experts`、`#expert/<id>` | 每位達人的紀錄數、涵蓋縣市、預計與實際到訪、達成率、每月長條圖 |
| 我的訪查 `#mine` | 依行程分組的預計到訪、完成進度、Google 地圖路線、快速填寫紀錄 |
| 新增紀錄 `#submit/<縣市>/<景點 id>` | 現況、開放、推薦指數與分項、心情、心得、建議、附近推薦、照片（縮圖並移除 GPS）、資料勘誤 |
| 申請 `#apply`、審查 `#admin` | 達人申請；審查者核准紀錄與申請、調整角色、稽核紀錄、勘誤清單 |

**三類文化資產**（資料來自兩個知識網站，`tools/build_index.py` 產生）：

| 類別 | 數量 | 記錄什麼 | 現況選項 | 對應知識網站 |
|---|---|---|---|---|
| 有形文資 | 3,032 處 | 到現場訪查 | 文資現況、開放情形 | 景點 `#map/<景點 id>` |
| 無形文資 | 624 項 | 參加祭典、看演出、體驗工藝（參與方式） | 傳承現況、公開情形 | 展示點 `#map/<展示點 id>`；沒有固定地點的連縣市首頁 |
| 古物 | 559 件 | 到展示點看實物 | 保存狀況、展示情形 | 展示點 `#map/<展示點 id>` |

三類分開統計，不合併計算覆蓋率。古物沒有官方編號，id 由「展示點＋名稱」產生。

**對應連結**：知識網站的景點詳情有「達人實地訪查・現況與推薦」、展示點詳情有「達人實地紀錄」與每項無形文資的「達人參與紀錄」，連到本站（`Cultural_Heritage/assets/js/city/app.js` 的 `VISIT_BASE`）。

## 示範模式與正式模式

- `assets/js/config.js` 沒填 Supabase ＝ **示範模式**：資料只存在瀏覽器，頁面上方黃色列可切換身分（管理者、達人、會員、訪客）試用所有流程。
- 填入 Supabase 的 Project URL 與 anon key ＝ **正式模式**：email 免密碼登入、多人共用資料、照片存 Supabase Storage。設定步驟見 `docs/PLAN.md`〈上線步驟〉。

## 照片

照片存在 Supabase Storage 的 `visit-photos`（不在資料庫、也不在 GitHub）。上傳前在瀏覽器裡處理：移除 EXIF（含 GPS），並產生兩張：

| | 長邊 | 約略大小 | 用途 |
|---|---|---|---|
| 大圖 `<…>.jpg` | 1280 像素 | 250 KB | 點開照片才載入 |
| 小圖 `<…>-t.jpg` | 480 像素 | 40 KB | 首頁、列表、紀錄卡片 |

尺寸與品質在 `assets/js/config.js`（`photoMaxPx`、`thumbPx`）。2026-11-07 以前上傳的照片沒有小圖，網頁會自動改用大圖。免費方案額度：儲存 1 GB（約 3,500 組照片）、每月流量 5 GB。

## Supabase 保持運作

Supabase 免費方案的專案 7 天沒有資料庫活動就會被暫停。`.github/workflows/supabase-keepalive.yml` 每天臺灣時間 09:17、21:17 自動讀取一次公開資料（不寫入、不需要任何密碼），讓專案保持運作。

- 讀取失敗（例如專案已被暫停）時 workflow 會失敗，GitHub 會寄信通知；到 Supabase 後台選專案按 **Resume project** 即可恢復
- 可在 GitHub 的 **Actions** 分頁選「Supabase 保持運作」按 **Run workflow** 手動執行
- repo 連續 60 天沒有更新時，GitHub 會自動停用排程並寄信通知，到 Actions 分頁按 **Enable workflow** 恢復
- 免費方案**沒有自動備份**，請另外定期匯出資料庫（含申請者個資，不可放公開 repo）

## 更新文資清單

知識網站新增或修改文資後：

```bash
python3 tools/build_index.py
```

預設讀本 repo 旁邊的 `Cultural_Heritage`、`Cultural_Heritage2`（或設環境變數 `CH1_DIR`、`CH2_DIR`）。

## 版本戳記

`index.html` 載入本站 CSS／JS 時帶 `?v=日期`（例如 `app.js?v=20261107b`）。修改 `assets/` 底下的 CSS 或 JS 之後，把 `index.html` 裡的 `?v=` 改成新的值，手機與平板才不會沿用舊快取。

## 啟動卡住的防護

- 登入狀態只在本分頁內排隊（不用瀏覽器跨分頁共用的鎖）：iPhone／iPad 上背景分頁被暫停時，新分頁不會因此卡在「載入中」
- 8 秒內讀不到登入狀態，先以訪客身分開啟並顯示提示列（請關閉其他本站分頁後重新整理）；之後讀到了會自動切回
- 15 秒後仍在啟動，畫面會說明卡在哪一步並提供「重新整理」
